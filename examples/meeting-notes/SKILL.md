# 会议纪要整理

## 输出格式

```markdown
## 结论
- ...

## 待办
- [ ] 事项 — 负责人 — 截止时间

## 风险
- ...
```

## 规则

- 只写记录里出现过的信息；缺失写「未定」，不要编。
- 待办缺负责人或时间时，放到「待确认」。
- 结论控制在 5 条以内。
